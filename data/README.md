# Data

This folder contains the Travel Vista WIL project CSV extracts:

- `destinations.csv` - travel packages based on the Seven World Wonders.
- `reviews.csv` - user ratings and review text.
- `visit_counts.csv` - visit, traveler, region, and revenue events.
- `user_preferences.csv` - generated user preference profiles.
- `activity_logs.csv` - user activity events for search, click, and platform behavior.

The files are synthetic/demo project data and are safe for a public portfolio repository.
